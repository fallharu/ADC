# 距離算出ロジックの概要

本システムにおける「離隔距離」および「白線距離」の算出計算式についてまとめます。

## 1. 離隔距離 (Clearance Distance)

追い越し車両（自動車）と追い越され車両（自転車）の間の水平方向の距離です。

- **単位**: メートル (m) および ピクセル (px)
- **計算式**:
  - **ピクセル距離**: 2つの車両のバウンディングボックス（BBox）の内側の端同士の差分をとります。
    - **自転車が左、車が右の場合**: `車.x1 (左端) - 自転車.x2 (右端)`
    - **車が左、自転車が右の場合**: `自転車.x1 (左端) - 車.x2 (右端)`
    - **重なっている場合**: `0`
  - **メートル換算**: `ピクセル距離 × スケール係数 (m/px)`

> **補足**: スケール係数は、キャリブレーションで設定された値（例: 0.005 m/px）を使用します。

---

## 2. 白線距離 (White Line Distance)

車両の「測定点（Measure Point）」から、左右の白線までの水平距離です。

### 2.1. 測定点の決定
車両が白線に対して「最も近い」または「基準となる」点を測定点としています。

| 対象 | 進行方向 | 測定点 (優先順位) | 代替点 (タイヤ未検出時) |
| :--- | :--- | :--- | :--- |
| **自動車** | **B (Top-to-Bottom)**<br>右側通行・奥から手前 | **右前輪** の接地点 | BBoxの右下 (`x2`, `y2`) |
| **自動車** | **F (Bottom-to-Top)**<br>左側通行・手前から奥 | **左前輪** の接地点 | BBoxの左下 (`x1`, `y2`) |
| **自転車** | - | **BBoxの下部中央** (Bottom-Center) | `x = (x1+x2)/2`, `y = y2` |

### 2.2. 計算式
測定点のY座標における白線のX座標を求め、水平距離を計算します。

- **左白線距離**: `abs(測定点.x - 左白線.x)`
- **右白線距離**: `abs(測定点.x - 右白線.x)`

### 2.3. 白線データの補間
白線は点群（ポリライン）として定義されています。測定点のY座標が白線の点と点の間にある場合、**線形補間**を用いて正確なX座標を算出します。

---

## 3. 中央線・白線越え判定

- **レーン内判定**: 左白線と右白線で形成されるポリゴン内に測定点が含まれるかを判定します。
- **越え量 (Cross Distance)**:
  - レーン外（マイナスフラグ）の場合、最も近い白線までの距離を「越え量」として記録します。
  - 進行方向に応じて「中央線」か「路側帯（白線）」かを区別します。
    - **Direction B (車両が右側)**: 左側が中央線、右側が路側帯（白線）
    - **Direction F (車両が左側)**: 右側が中央線、左側が路側帯（白線）
