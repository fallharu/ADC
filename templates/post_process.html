    フォルダ単位で後処理を実行
    選択したフォルダに属するRunを順番に処理します。未完了のRunも自動的に対象になります。
    指定するとフォルダ内の全Runに同じプロファイルを設定してから後処理を実施します。
    空欄の場合はフォルダ全体が対象です。サブフォルダを複数指定する場合は改行で区切ってください (\ を含むパスも自動的に / へ変換されます)。
    フォルダ内のサブフォルダごとに適用するプロファイルを一覧から選択できます。
    条件を指定して後処理を実行

    指定した条件に一致するすべてのRunを一括処理します。

    対象Run数が多くなる可能性があります。実行前に確認してください。
    Run ID範囲で後処理を実行

    開始と終了のRun IDを入力すると、指定範囲内のRunを順番に後処理キューへ登録します。

    Run IDの昇順で処理します。エラーが発生したRunは記録して次のRunへ進みます。

    ラベルと線の表示内容を必要に応じて切り替えできます。
