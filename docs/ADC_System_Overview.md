# ADCシステム 概要資料

## 1. タイトル
**ADCシステム 概要資料**
交通流調査・安全解析のためのAI自動化ソリューション

---

## 2. システム概要
**コンセプト**: 交通流調査や安全解析を効率化するAIシステム
**スコープ**: 車両・自転車の検出、追跡、速度計測、距離計測を一気通貫で実施

**主なターゲット**:
*   交通コンサルタント
*   道路管理者
*   研究機関

---

## 3. 解析ワークフロー
1.  **入力 (Input)**
    *   動画ファイルの読み込み（フォルダ一括処理 / 個別ファイル指定）
2.  **設定 (Setup)**
    *   キャリブレーション（カメラアングル補正、車線幅設定）
3.  **解析 (Process)**
    *   AIによる物体検出 & ロジック計算（速度推定・距離計測）
4.  **検証 (Verify)**
    *   手動補正ツールによる目視確認（データの信頼性を担保）
5.  **出力 (Output)**
    *   レポート出力（Excel/CSV/アノテーション動画）

## 4. 特徴1：柔軟なキャリブレーション
画面上のピクセルを現実空間のメートル単位へ高精度に変換

*   **簡単なWeb UI操作**
    *   画面上で白線をなぞるだけでスケール計算が可能
*   **設定のプロファイル保存**
    *   定点カメラなどで同じ設定を繰り返し利用可能
    *   設置角度や高さが異なる映像にも柔軟に対応

## 5. 特徴2：高度な解析指標（追い越し・離隔）
「自動車による自転車の追い越し」イベントを自動抽出

*   **離隔距離 (Clearance Distance)**
    *   車両と自転車の間の最短距離をセンチメートル単位で算出
*   **白線からの距離 (Line Distance)**
    *   車両が走行レーン内のどの位置を走っているかを定量化
*   **速度差・相対速度**
    *   追い越し時の速度差や危険度を評価

## 6. 特徴3：手動検証・補正 (Human-in-the-loop)
AIの完全自動化ではない、人が最終判断を行う設計思想

*   **イベント編集機能**
    *   AIによる誤検知を削除、または未検知を手動で追加
*   **データの信頼性確保**
    *   学術研究や行政報告にも利用可能な、100%正確なデータセットを作成可能
    *   修正履歴の管理と再計算の自動化

## 8. まとめ
*   **高効率 (High Efficiency)**
    *   GPU対応による高速バッチ処理で、大量の動画データを短時間で解析
*   **高精度 (High Precision)**
    *   独自のキャリブレーション技術とロジックに加え、手動補正で精度を担保
*   **統合ソリューション**
    *   解析からレポート作成までをワンストップで提供するWebアプリケーション
