# ADC System 仕様書

## 1. システム概要
本システムは、走行動画を解析し、車両の検出、追跡、速度推定、および追い越しイベントの特定を自動化する交通流解析システムです。YOLO モデルを用いた物体検出と、独自のロジックによる追跡・計測機能を組み合わせ、Web インターフェースを通じて操作・結果確認が可能です。

## 2. システム構成
本システムは、以下の技術スタックで構成されています。

*   **言語**: Python 3.x
*   **Webフレームワーク**: Flask
*   **データベース**: SQLite (軽量・高速なファイルベースDB)
*   **画像処理・AI**:
    *   Ultralytics YOLO (物体検出・追跡)
    *   OpenCV (動画処理)
    *   PyTorch (CUDA対応GPU推論)
*   **フロントエンド**: HTML5, CSS3, JavaScript (Jinja2 テンプレートエンジン使用)

## 3. 機能要件

### 3.1 動画管理機能
*   **動画アップロード**: ユーザーは Web UI から動画ファイル (`.mp4`, `.avi`, `.mov`) をアップロード可能。
*   **動画一覧表示**: アップロード済み動画のステータス（未処理、処理中、完了）とメタ情報を管理。
*   **フォルダ別設定**: 動画フォルダごとにキャリブレーションプロファイルや自動処理設定を適用可能。

### 3.2 自動解析機能 (Inference)
*   **物体検出**: YOLO モデル (v8/v11) を使用し、車両（自動車、バス、トラック等）およびタイヤを検出。
*   **トラッキング**: ByteTrack 等のアルゴリズムを用い、フレーム間で同一車両を追跡 (`track_id` の付与)。
*   **速度推定**:
    *   カメラパラメータ（キャリブレーション）に基づき、画像上の移動量から実速度 (km/h) を算出。
    *   画素速度 (px/frame) および 加減速状態（加速・減速・巡航）の判定。
*   **車間距離・位置計測**:
    *   前方車両との車間距離 (Approach Distance) 計測。
    *   白線（レーン）からの距離計算および走行レーン（内側・外側）の判定。
    *   横方向（Clearance）距離の計測。
*   **追い越し検出 (Overtake Detection)**:
    *   相対速度と位置関係に基づき、追い越しイベントを自動判定。
    *   追い越し車両 (Overtaker) と被追い越し車両 (Overtaken) のペアリング。

### 3.3 手動アノテーション・補正機能
*   **手動追い越しイベント登録**:
    *   自動検出で漏れたイベントや、誤検出を手動で修正・登録する機能。
    *   専用 UI にて、タイムライン上でのイベント管理、前後フレームの確認が可能。
*   **レーン幅・計測補正**:
    *   レーン幅 (m) の手動入力・修正。
    *   計測ポイント（白線位置、車両位置）の微調整機能。

### 3.4 データ出力・レポーティング
*   **結果のエクスポート**:
    *   Excel 形式 (`.xlsx`): 統計データ、詳細ログを見やすく整形して出力。
    *   CSV 形式: 生データ詳細。
*   **動画生成**:
    *   検出ボックス、ID、速度、判定ステータス等をオーバーレイした解析済み動画の書き出し。
*   **統計表示**:
    *   全体および動画ごとの検出数、速度分布、追い越し回数等の統計情報をグラフ/表で表示。

## 5. 運用データ統計 (現在値)

現在のデータベース (`my_app_data.db`) に蓄積されている解析データ規模は以下の通りです。

*   **登録動画数**: 156 件
*   **総検出オブジェクト数**: 1,154,640 件 (車両・タイヤ等)
*   **手動記録イベント数**: 48 件 (追い越しイベント等)

これらのデータは、日々の解析により蓄積され、交通流の詳細な分析に活用されます。

## 6. データベース設計 (SQLite)

主なテーブル構成は以下の通りです。

### 4.1 ProcessLog (処理ログ)
動画ごとの解析実行単位 (Run) を管理します。
*   `run_id`: 主キー
*   `video_id`: 解析対象動画
*   `status`: 処理状態 (completed, processing, error)
*   `process_date`: 処理日時

### 4.2 Detection (検出データ)
フレームごとの全検出オブジェクト情報を格納します（数百万行規模になる可能性あり）。
*   `run_id`, `frame_num`: どの動画のどのフレームか
*   `track_id`: 追跡ID
*   `class_id`: 車種クラス
*   `x1`, `y1`, `x2`, `y2`: バウンディングボックス座標
*   `speed_km_h`: 推定速度
*   `line_distance`: 白線からの距離

### 4.3 ManualOvertakeEvents (手動追い越しイベント)
手動で追加・編集された重要なイベント情報を管理します。
*   `manual_event_id`: 主キー
*   `overtaker_group_id`: 追い越し側の車両グループ
*   `overtaken_group_id`: 被追い越し側の車両グループ
*   `notes`: ユーザーメモ

## 5. ディレクトリ構成
*   `Source_code/`: アプリケーションの主要ソースコード
    *   `app.py`: エントリーポイント
    *   `routes.py`: Web ルーティング定義

*   `templates/`: HTML テンプレート
*   `db/`: SQLite データベースファイル格納場所
*   `uploads/`: アップロード動画保存場所
*   `output/`: 解析結果（動画、Excel）出力先
